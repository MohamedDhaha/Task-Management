# 🗂 Task Management App

A modern **Task Management Application** built with **Next.js**, **TypeScript**, and **Tailwind CSS**, designed to help users organize tasks efficiently with a clean and responsive interface.

---

## 🚀 Features

* ✅ Create, update, and delete tasks
* 📌 Organize tasks efficiently
* ⚡ Fast performance with Next.js
* 🎨 Clean UI with Tailwind CSS
* 🧩 Reusable components structure
* 📱 Fully responsive design

---

## 🛠 Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui
* **Package Manager:** npm / pnpm

---

## 📁 Project Structure

```bash
task-management/
│
├── app/                # Next.js app directory (routes & pages)
├── components/         # Reusable UI components
├── hooks/              # Custom React hooks
├── lib/                # Utility functions
├── public/             # Static assets
├── styles/             # Global styles
│
├── next.config.mjs     # Next.js configuration
├── tailwind.config.ts  # Tailwind configuration
├── tsconfig.json       # TypeScript config
├── package.json        # Dependencies & scripts
└── README.md           # Project documentation
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Amjath776/Task-Management.git
cd Task-Management
```

---

### 2. Install dependencies

```bash
npm install
```

*or (recommended if using pnpm):*

```bash
pnpm install
```

---

## ▶️ Run the Development Server

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

---

## 🧪 Build for Production

```bash
npm run build
```

---

## 📦 Start Production Server

```bash
npm start
```
